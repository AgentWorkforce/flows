## The one real blocker: scheduled runs get no code

A cloud **manual** run materializes the repo (the CLI uploads the `git
ls-files` set, bootstrap extracts it into the code mount). A cloud
**scheduled** run does not — its workdir `/project/workflows/schedules/<id>`
is empty, so `sync` fails closed.

Established by reading cloud, not inferred:
- `packages/web/app/api/v1/workflows/schedules/route.ts` and
  `.../schedules/trigger/route.ts` contain **no** code-sync, upload, archive,
  or snapshot logic at all.
- `packages/web/lib/workflows/relayfile-mount.ts:150-172` picks the right
  mount path (`schedules/<key>` vs `runs/<key>`) and its comment refers to
  "the initial seed" — implying the mount is meant to be seeded once and
  reused across ticks. **Nothing seeds it.**
- `agent-relay cloud` has no verb that writes into a relayfile root, so this
  cannot be fixed from the CLI as it stands.

**The fix is a cloud change**, one of:
1. `agent-relay cloud schedule` captures the code snapshot at schedule-creation
   time and the trigger route materializes it into the schedule mount before
   launch (matches the "initial seed" design intent); or
2. the trigger route copies the most recent successful run's snapshot forward.

Not started. This is the single thing between cloud ticks and delivered work.

### On #1, what actually changed

`workflows/drive.yaml`'s review step now classifies every finding as
**BLOCKING** (wrong/unsafe/out-of-scope behavior, a gate that cannot fail, or
a false claim about verification) or **ADVISORY** (right code, imprecise
account of it — wrong citation, inverted mechanism, overstated prose). Only
BLOCKING fails the run; advisory findings are carried under their own heading
so they are fixed rather than lost.

The careful edge Khaliq asked for is written into the rubric explicitly: **a
false claim about verification is always blocking.** The whole program's trust
rests on those claims being literal, so that class was deliberately not
relaxed.

Context for why this was needed: ticks 8–17 were rejected ten times in a row,
overwhelmingly on advisory-class findings, while the behavior under review was
sound.

## B1 — live worker reported absent

`sdk/src/cli/run.ts` classified a runnable out-of-band step before a concurrent
running step. It therefore returned exit 3 with “no worker is attached” even
when the protocol hub had attached and dispatched a worker. The snapshot did
not expose worker attachment, so the CLI had no kernel fact supporting that
message. A running step without `lease_deadline_ms` also escaped as
`protocol_error` instead of being re-polled.

## B2 — durable crashed run refused forever

`kernel/relayflowd/src/server.rs` treated a missing registry row as proof that
the run did not exist. That pre-check returned `run_not_found` before the
engine could open the durable journal and repair its rebuildable locator. A
crash after `run.spawned` but before `Registry::register` therefore made the
run permanently unresumable.
